# T40 Result - Round3 Interaction Delivery

## Scope
Round3 implementation for:
- 快速筛选预设（今日/昨日/7天/本月/自定义）
- 一键视图切换（成本/性能/项目）
- 收藏视图
- 导出快照（CSV 或当前视图）

## Delivered
- Session one-click view switch now only includes `成本视图` / `性能视图` / `项目视图`.
- Favorite views remain a separate workflow (`收藏视图` save/apply/delete), and legacy favorites with invalid `sessionView` values are safely downgraded to `cost`.
- Export now supports two explicit modes:
  - `导出 CSV（全部筛选结果）`
  - `导出当前视图快照（JSON）`
- Export data scope is explicit and non-breaking:
  - Sessions tab: CSV exports all filtered rows; view snapshot exports current page rows.
  - Billing tab: CSV exports all filtered ledger rows; view snapshot exports current visible range rows.

## Non-regression
- Existing filter chain remains unchanged:
  - `getDatePresetRange`
  - `getFilteredSessionRows`
  - `filterRowsByDayRange`
- Round3 work only reuses their derived results and does not alter filter semantics.
