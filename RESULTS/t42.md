# T42 Result - Round1 Homepage + Pricing Route Migration

## Scope
Round1 implementation request:
- 首页顶部信息带（数据源徽标、最近更新时间、新鲜度、刷新按钮与状态）
- 首页关键卡片（今日花费/本月累计/预算进度/24h趋势）
- 基础异常角标
- 模型价格表迁移到独立页面（`/settings/pricing`），首页仅保留入口
- 最小侵入实现并完成测试与构建

## Delivered
- Homepage now includes a dedicated `顶部信息带` section with:
  - source badges (`Codex 本地`, `OpenClaw / OAuth` when available)
  - latest update timestamp + relative freshness
  - freshness badge and baseline anomaly badge
  - refresh button + refresh status badge/message
  - pricing entry CTA (`进入 设置/模型价格`)
- Homepage now includes `首页关键卡片` with:
  - `今日花费`
  - `本月累计`
  - `预算进度` (based on configured daily spend threshold)
  - `24h趋势` (delta vs yesterday)
- Homepage `限制窗口` section no longer renders the full pricing table; it keeps only an entry card.
- Added standalone `设置 / 模型价格` page at `/settings/pricing` that renders the full pricing table and supports back navigation to home.
- Added backend support for new flow:
  - `POST /api/refresh` for manual snapshot refresh
  - GET/HEAD `/settings/pricing` fallback to `index.html` for direct route access and browser refresh reliability
