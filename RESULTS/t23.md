# T23 Result

## Outcome

The frontend is no longer a static HTML/CSS/JS page.

It now builds from:

- `src/App.jsx`
- `src/components/ui/*`
- `src/lib/dashboard-logic.mjs`
- `src/index.css`
- `vite.config.mjs`

The UI uses local shadcn-style component source (`Button`, `Badge`, `Card`, `Tabs`, `Dialog`, `Input`, `Table`) and is compiled by Vite into the served `public/` directory. The existing Node API (`/api/snapshot`, `/api/source`, `/api/stream`) remains the data/backend boundary.
